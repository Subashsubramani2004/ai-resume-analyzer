# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes against job descriptions, calculates an ATS-style match score, identifies missing skills, and provides personalized improvement suggestions using Google Gemini.

---

## ✨ Features

* 🔐 User Registration & Login with JWT Authentication
* 📄 Upload and analyze PDF/DOCX resumes
* 🧠 Automatic resume text and skill extraction
* 🎯 Job description skill matching
* 📊 ATS-style resume score
* 🤖 AI-powered improvement suggestions using Google Gemini
* 📚 Analysis history
* 🗑️ Resume and analysis management
